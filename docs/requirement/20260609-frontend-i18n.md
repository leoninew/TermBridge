# 前端 i18n 支持范围说明

Review status: Accepted

Flow mode: light
Stage: Scope note

## Goal

- 为前端引入最小可用的 i18n 支持，使界面文案可以从集中式 locale 资源读取。
- 默认保留当前中文体验，并为英文文案预留结构。
- 覆盖当前主要页面和组件中的用户可见静态文案、placeholder、title、aria-label、弹窗说明和前端 fallback 错误文案。
- 提供一个最小语言切换入口，支持在 `zh-CN` 与 `en-US` 之间切换。

## Non-goal

- 不翻译用户数据、系统数据或运行时数据，例如会话名、目录路径、终端命令、端口号。
- 不要求翻译后端返回的 detail/message；前端只翻译无法取得后端错误详情时的 fallback 文案。
- 不引入复杂语言偏好持久化、远程翻译加载或运行时翻译管理后台。
- 不改变现有页面布局、交互流程或业务行为。

## Acceptance

- 前端具备 i18n 初始化入口，并在 Vue app 中启用。
- 至少提供 `zh-CN` 和 `en-US` 两套 locale 资源文件；`zh-CN` 为默认语言。
- 页面提供语言切换入口，可在 `zh-CN` 与 `en-US` 间切换当前界面语言。
- 当前硬编码中文用户界面文案迁移到 locale key。
- 动态文案使用参数化翻译，例如删除确认、状态提示、请求失败状态码。
- 项目现有前端检查命令可以通过，优先运行 `npm run typecheck`、`npm run lint` 或 `npm run build` 中可用的相关命令。

## Risk

- 如果后端错误详情是中文，前端无法可靠翻译，只能原样显示。
- 枚举值如 session status、terminal source、enabled/hidden 状态需要额外映射，否则会出现英文枚举与翻译文案混用。
- 一次性替换所有文案容易遗漏 aria/title/placeholder，需要验证时重点检查。
