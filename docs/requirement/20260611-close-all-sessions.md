# 关闭所有会话轻量范围说明

Review status: Accepted

## Goal

在设置中增加“关闭所有会话”能力，供用户一次性停止当前所有 TermBridge 会话对应的 tmux 资源。

用户点击该能力后，应先看到警告样式确认模态窗；确认后系统遍历环境和会话，关闭对应 tmux window/session，并刷新前端会话状态。

## Non-goal

- 不删除会话管理记录。
- 不删除快捷方式、环境配置或工作区数据。
- 不新增后台定时清理机制。
- 不改变单个会话停止的语义。

## Acceptance

- 设置中有可见的“关闭所有会话”危险操作入口。
- 点击入口后弹出警告/破坏性样式确认模态窗。
- 取消确认不会关闭任何会话。
- 确认后遍历所有环境和会话，复用现有单会话 stop 语义关闭 tmux window/session。
- 操作完成后保留会话管理记录，并刷新前端会话状态。
- 操作成功时展示 toast 反馈；失败时展示错误反馈。

## Risk

- 批量关闭是高影响操作，必须二次确认。
- 批量操作中若某个会话关闭失败，需要避免前端误以为全部成功。
- 后端应尽量复用现有单会话停止逻辑，避免单会话和批量关闭语义分叉。
