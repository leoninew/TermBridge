# 会话创建与导航 UI 调整范围说明

Review status: Accepted

当前：轻量模式 / light，范围说明 / Scope note

## Goal

- 将「创建 session」从左侧常驻表单调整为会话管理内的轻量入口。
- 左侧区域主要用于会话管理与会话列表，而不是占用空间展示创建表单。
- 创建 session 体验应在会话管理卡片内自然完成，避免额外弹窗或抽屉打断上下文。
- 将 UI 中的 `Runtime` 概念改为更符合用户理解的「终端」。
- 支持用户自定义终端命令，而不只是在固定 runtime 列表中选择。
- 改善 Workspace 选择体验，避免只依赖手写文本框。
- Workspace 选择应基于后端可见的真实本机路径，而不是浏览器目录选择 API 返回的目录名。
- 后端关键流程需要日志，便于排查 session 创建、端口分配、进程启动和状态刷新问题。
- 后端异常和模型应从业务逻辑中分离，降低 service/repository/runtime 等模块的混杂度。

## Non-goal

- 不重做完整视觉设计系统。
- 不引入用户认证、权限、多用户能力。
- 不改变 ttyd session 的核心生命周期语义。
- 不实现远程文件系统浏览，只针对后端本机可见 workspace 选择体验做轻量改进。
- 前端暂不实现“显示隐藏目录”checkbox，只要求后端预留控制参数。

## Acceptance

- 左侧导航/侧栏以会话管理为主，创建入口不再是常驻大表单。
- 会话管理卡片右上角提供加号创建入口。
- 点击创建入口后，会话管理卡片内容平滑切换为创建 session 表单。
- 创建成功或取消后，会话管理卡片平滑还原为会话列表。
- 创建表单中 `Runtime` 文案改为「终端」。
- 用户可以选择内置终端，也可以输入自定义终端命令。
- Workspace 字段支持手动输入真实路径，也支持通过目录树选择后端可见真实路径。
- Workspace 目录树作为可复用组件，不绑定弹窗/抽屉/就地展示形态；当前在表单字段内就地使用。
- Workspace 选择器与表单字段集成，提示文案简化到 placeholder，不额外占用说明区域。
- 点击目录树节点时自动写入 workspace，不需要额外“使用”按钮。
- 已选 workspace 再次展开目录树时，目录树应自动展开并定位到该目录。
- 目录树默认不展示隐藏目录；后端预留 `show_hidden` 控制参数，前端暂不实现控制入口。
- 目录树展示保持简洁：较小字号，不展示每行右侧完整路径。
- 现有 session 列表、选择、删除、iframe 打开终端能力保持可用。
- 后端关键步骤日志覆盖 session 创建、workspace 校验、终端命令解析、端口分配、ttyd 启动、删除和状态刷新。
- 后端自定义异常集中到独立异常模块；模型仍集中在模型模块，避免和业务逻辑混在一起。
- `make fastapi` 开启后端热更新，便于开发时加载新增 API。

## Decisions

- 放弃依赖浏览器 `showDirectoryPicker` 作为 Workspace 真实路径来源，因为浏览器通常不能提供完整本机绝对路径。
- Workspace 选择改为后端目录树 API：前端从后端返回的磁盘根和目录节点中选择真实路径。
- 默认目录浏览范围为 Windows 磁盘根目录；非 Windows 环境可降级到 `/`。
- 创建 session 最终不采用模态窗或左侧抽屉，而是在会话管理卡片内原地切换。
- Workspace 目录选择组件保持独立可复用，使用方式由父组件决定。
- 隐藏目录当前只在后端实现默认过滤和参数预留，前端控制项以后再做。

## Risk

- 后端目录树枚举的是后端进程可见路径；Windows / Cygwin / WSL 路径表达不同，后续可能需要根据实际运行环境继续细化。
- 支持自定义终端命令会涉及请求模型和命令构造方式调整，需要避免 shell 注入；当前命令不经 shell 执行。
- 磁盘根目录浏览可能遇到无权限或系统目录，目录树需要跳过不可访问目录，避免整个请求失败。
- 隐藏目录识别在 Windows 和类 Unix 环境语义不同，当前以后端实现为准。
