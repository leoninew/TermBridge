# 前端 i18n 支持验证

Review status: Draft

Flow mode: light
Stage: Verification

## What changed

- 新增 `vue-i18n` 依赖，并在前端入口启用 i18n。
- 新增 `frontend/src/i18n/index.ts`，默认语言为 `zh-CN`，fallback 为 `en-US`。
- 新增 `frontend/src/i18n/locales/zh-CN.json` 和 `frontend/src/i18n/locales/en-US.json`。
- 将主要用户可见文案迁移为 locale key，包括导航、会话创建、会话列表、会话卡片、终端展示、目录浏览、终端管理、删除确认和前端 fallback 错误文案。
- 将 session status、terminal source、terminal availability 等枚举展示改为翻译文案。
- 在顶部导航区域新增语言切换入口，可切换 `zh-CN` 与 `en-US`。

## Acceptance

- [x] 前端具备 i18n 初始化入口，并在 Vue app 中启用。
- [x] 提供 `zh-CN` 和 `en-US` 两套 locale 资源文件；`zh-CN` 为默认语言。
- [x] 页面提供语言切换入口，可在 `zh-CN` 与 `en-US` 间切换当前界面语言。
- [x] 当前组件中的硬编码中文用户界面文案已迁移到 locale key。
- [x] 删除确认、状态提示、请求失败状态码等动态文案使用参数化翻译。
- [x] 用户数据、系统数据或运行时数据未翻译，例如会话名、目录路径、终端命令、端口号。
